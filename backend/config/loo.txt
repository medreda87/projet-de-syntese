──────────────────────────────────────────────
SERVICE 1 — Smart Routing (Mobile)
──────────────────────────────────────────────
Purpose: Real-time GPS navigation avoiding congestion
UI components:
  - Full-screen map (use Leaflet.js with OpenStreetMap tiles)
  - Search bar: "From" and "To" with autocomplete
  - Route options panel: Fastest / Least traffic / Eco mode
  - ETA display card: time, distance, CO2 saved
  - Live incident banner (red bar when road blocked ahead)
  - "Share ETA" button → generates shareable link
  - Voice guidance toggle
AI inputs needed:
  - user_gps: {lat, lng, speed, heading}
  - destination: {lat, lng, name}
  - traffic_density_grid: 2D heatmap of road congestion (0–100)
  - incidents: [{type, lat, lng, severity, timestamp}]
  - time_of_day: ISO8601 string
AI outputs:
  - recommended_route: [{lat, lng}] polyline
  - eta_minutes: number
  - alternative_routes: array of 2 fallback routes
  - reroute_trigger: boolean

SERVICE 2 — Parking Finder (Mobile)
──────────────────────────────────────────────
Purpose: Find and reserve real-time parking spots
UI components:
  - Map with parking zone markers (color: green=available, red=full, amber=filling)
  - Filter bar: price range slider, covered/open toggle, distance radius
  - Parking card: name, price/hour, available spots count, distance
  - Reserve button → shows confirmation modal with timer countdown
  - "Navigate to parking" CTA
  - Notification: "Your zone is 80% full — 3 spots left"
AI inputs needed:
  - user_location: {lat, lng}
  - parking_zones: [{id, lat, lng, total_spots, occupied_spots, price_per_hour, covered}]
  - reservation_db: current active reservations
  - historical_fill_rate: {zone_id, hour_of_day → avg_occupancy_%}
AI outputs:

  - fill_prediction_30min: % occupancy in 30 minutes

PART 7 — AI INTEGRATION NOTES
═══════════════════════════════════════════════

For each service, the AI layer works as follows:

Input pipeline:
  sensors → normalize → feature_vector → model_inference → output

In the frontend demo, simulate AI outputs using:
  - Pre-computed mock responses in /src/ai/mockResponses.ts
  - Add 800ms artificial delay to simulate inference time
  - Show "AI thinking..." skeleton while waiting
  - Label all AI-generated content with a small "AI" badge

When integrating real AI later:
  - All AI calls go through /api/ai/{service_name} endpoint
  - Inputs: JSON matching the schema defined in each service above
  - Outputs: JSON matching the output schema
  - Model type per service:
    Routing → Graph Neural Network + OSRM
    Parking prediction → XGBoost time-series
    Crowd counting → YOLOv8 object detection
    Lost & Found matching → CLIP image embeddings + cosine similarity
    Decision Assistant → LLM (Arabic-capable: Jais or AraGPT2)
    Best time to leave → LSTM traffic forecast
    All signal optimization → MARL (Multi-Agent RL, RLlib framework)
