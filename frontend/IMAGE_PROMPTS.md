## Technical Specifications

### Image Dimensions Recommended:
- **Hero Images**: 1920x1080px (16:9) or 1920x800px
- **Component Images**: 1200x600px (2:1 ratio)
- **Icon Images**: 512x512px (square, SVG preferred)
- **Profile Images**: 400x400px (square)
- **Banner Images**: 1920x1080px
- **Thumbnail Images**: 300x300px (square)

### Color Palette:
- **Primary Blue**: #0EA5C9
- **Accent Green**: #1BB38C
- **Text Dark**: #1E2A36
- **Text Gray**: #62707D
- **Background Light**: #F7F9FA
- **Primary Light**: #E0F2FE

### Style Guidelines:
- Clean, modern aesthetic
- Professional photography or illustration
- Bright, welcoming atmosphere
- Trustworthy and reliable feeling
- Consistent color scheme
- High quality, sharp images
- Authentic, diverse representation

## Usage Notes

1. **Consistency**: Maintain consistent style across all images
2. **Brand Colors**: Use FreshFold color palette (blue and green)
3. **Quality**: Use high-resolution images (minimum 2x for retina displays)
4. **Optimization**: Compress images for web use while maintaining quality
5. **Accessibility**: Include alt text descriptions for all images
6. **Diversity**: Ensure diverse representation in people images
7. **Authenticity**: Use real, authentic-looking imagery over stock photos when possible

## AI Image Generator Tips

### For DALL-E:
- Use detailed, specific descriptions
- Mention "professional photography" or "illustration style"
- Specify color schemes
- Include composition details

### For Midjourney:
- Use `--style raw` for more realistic photos
- Use `--ar 16:9` for hero images
- Add `--v 6` for latest version
- Use `--quality 2` for higher quality

### For Stable Diffusion:
- Use appropriate models (Realistic Vision, DreamShaper)
- Set high resolution (1024x1024 or higher)
- Use detailed prompts with style keywords
- Adjust CFG scale for better adherence
